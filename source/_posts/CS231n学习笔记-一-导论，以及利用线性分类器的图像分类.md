## KNN

K-近邻算法是一个经典的ML算法，并不适合用在图像处理中，主要原因是：

1. 训练快(只需要将训练集保存起来, $O(N)$ ), 但推理慢(需要计算输入和每一个训练数据的距离 $O(M\times N)$ )。
2. 不管用什么距离算法，都不能很好的衡量两个图片的差别。

## 习题解析

实现L2距离计算:

```python
dists[i, j] = np.sqrt(((X[i] - self.X_train[j]) ** 2).sum())
```

将测试集和训练集中所有图片分别计算L2距离，绘制如下图：

上图中白色表示距离远，黑色表示距离近。习题要求解释出现明亮行和列的原因。不难想到，每一行表示一个测试例，每一列表示一个训练例。因此，导致出现明亮行的数据，是一个与大部分测试例L2距离都很远的训练例；同理，导致出现明亮列的数据，是一个与大部分训练例L2距离都很远的测试例。
接下来实现`predict_labels`方法，首先要求实现我们获取前k近的标签，作业的建议是使用`np.argsort`，但最好使用`np.argpartition`:

```python
closest_y = self.y_train[np.argpartition(dists[i, :], k - 1)[:k]]
```

然后获取前k近的标签中出现次数最多的标签，并作为预测结果；如果有出现次数相同的标签，则选择最小的标签：

```python
val, count = np.unique(closest_y, return_counts=True)
y_pred[i] = val[count==np.max(count)][0]
```

这一段实现有点tricky，实际上是利用了`np.unique`函数不仅会返回所有元素出现的次数，还会自动排序元素的性质。这样我们只要取`val[count==np.max(count)]`的首元素，就自然能解决有多个出现次数相同的元素的场景。  
当`k=1`时，正确率为$27.4\\%$，当`k=5`时，正确率为$27.8\\%$。考虑到我们一共只有7类，目前KNN分类器的准确率只比$\frac{1}{7}$高$10\\%$  

Inline Question 2:  
这个问题要我们解答一系列操作是否会在L1距离下改变k-NN分类器的结果, 并不难, 分析如下:

$$ L_1=\sum_{i,j}\left|{p^{(n)}_{ij}} - p^{(m)}_{ij}\right| $$

1. 所有的像素都减去平均值
$$L_1=\sum_{i,j}\left|{(p^{(n)}_{ij}} - \mu) - (p^{(m)}_{ij} - \mu)\right| = \sum_{i,j}\left|{p^{(n)}_{ij}} - p^{(m)}_{ij}\right| $$
不会改变，因为每个像素都减去相同值，并不会改变任意两个像素之间的差值，因此不会改变两张图片的L1距离。  
2. 所有的像素都减去对应位置像素的平均值
$$L_1=\sum_{i,j}\left|{(p^{(n)}_{ij}} - \mu_{ij}) - (p^{(m)}_{ij} - \mu_{ij})\right| = \sum_{i,j}\left|{p^{(n)}_{ij}} - p^{(m)}_{ij}\right|$$
不会改变，因为计算L1距离时是计算两个图片相同位置的像素之间的差值，减去相同的常数不会改变差值。
3. 减去全像素平均值后，再除以全像素标准差
$$L_1=\sum_{i,j}|\frac{{p^{(n)}_{ij}}-\mu}{\sigma} - \frac{p^{(m)}_{ij} - \mu}{\sigma}| = \frac{1}{\sigma}\sum_{i,j}|{p^{(n)}_{ij}} - p^{(m)}_{ij}|$$
相当于所有图像之间的距离都变为$\frac{1}{L}$,不会影响图像之间距离的大小关系。
4. 减去对应像素平均值后，再除以对应像素的标准差
$$L_1=\sum_{i,j}\left|\frac{{p^{(n)}_{ij}}-\mu_{ij}}{\sigma_{ij}} - \frac{p^{(m)}_{ij} - \mu_{ij}}{\sigma_{ij}}\right| = \sum_{i,j}\left|\frac{1}{\sigma_{ij}}\left({p^{(n)}_{ij}} - p^{(m)}_{ij}\right)\right|$$
对应像素的平均值没有产生影响，但除以对应像素的标准差，导致了不同像素的差值对于L1距离具有不同的权重。会对模型效果产生影响。
5. 将图像旋转任意角度，不进行插值，造成的空白填充相同的数值
如果将图像旋转90/180/270度，L1距离不会发生变换。但如果旋转的是其他角度，由于部分像素被丢弃，并填充相同的数值，等同于抹除了这一部分像素的距离。由于不同图像之间对应像素的距离不同，会导致不同图像之间的L1距离大小关系发生变化。
